# NovaTerm site

Public GitHub Pages site for NovaTerm, providing the Store-required pages:

- Landing page: https://debashis-1987.github.io/novaterm-site/
- Privacy policy: https://debashis-1987.github.io/novaterm-site/privacy/
- Support: debashis.mca@hotmail.com

Everything is static HTML with inline CSS — no build step, no external requests,
and no third-party scripts.

## Editing

- `index.html` — landing page
- `privacy/index.html` — privacy policy (keep in sync with `store/privacy-policy.md`
  in the main NovaTerm repo)

Commit to `main`; GitHub Pages redeploys automatically.

## Contact

The policy and footer point to `debashis.mca@hotmail.com`. Keep that mailbox
monitored — it is the Store support contact.
